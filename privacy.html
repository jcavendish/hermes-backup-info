Hermes VPS Backups privacy policy

Last updated: 15 September 2026.

This private integration is operated solely for its owner's recovery needs. It is not offered to other users.

Google Drive access

The integration requests the drive.file permission to create and manage its own encrypted backup files and folder. It reads file metadata, such as size and checksum, to verify uploads. It does not request general access to the owner's Drive.

Storage and use

Recovery snapshots can contain private Hermes application data and credentials. Each snapshot is encrypted before being sent to Google Drive. The decryption key is held separately from the server. The Google authorization token is stored privately on the backup server and used only to create, verify, and retrieve backups.

Backup data is not sold, used for advertising, or used to train machine-learning models by this integration. Google processes stored files and API requests under its applicable terms. This informational website receives no backup data.

Retention and control

Backups remain in the owner's Drive until the owner removes them. The owner can revoke this integration through their Google Account's connected-app settings and delete its backup folder from Drive. Revoking access stops future uploads but does not delete existing backups.

Contact

The owner can use the support email shown on this integration's Google consent screen for questions or recovery administration.
